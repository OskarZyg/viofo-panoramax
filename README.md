# viofo-panoramax

A utility to transform viofo clips to panoramax sequences for use in OpenStreetMap mapping and beyond!

# features (ongoing)

This project is still in the PoC phase.

- [x] (functional but not precise) technical extraction of videos to geotagged photos with correct metadata
- [ ] create a functional command line utility to run the program
- [ ] create a functional command line utility that interacts with viofo api/sdk to automatically upload videos as tracks to panoramax
- [ ] create a command line utility that does this over the camera's wifi network also, reducing the use for moving physical storage mediums
